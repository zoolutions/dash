# Plans

Plans for this repository live in **GitHub issues** on `zoolutions/dash`. There is no `docs/plans/` directory and `docs/` is the published documentation site, not a scratch space — do not add plan markdown there.

- A plan that will be executed: a GitHub issue, labelled and referenced from the branch's commits (`Refs #123`).
- `../ROADMAP.md` holds the standing, evidence-linked improvement list. A new theme belongs there; a single piece of work belongs in an issue.
- Working notes, gate diffs and handovers go in `../tmp/`, which is git-ignored and never committed.

`/lode:plan --file` has no committed path in this repository; ask for an issue instead.
